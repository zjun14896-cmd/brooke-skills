# Brooke's Skills

我做的 AI Skills 合集。每个文件夹是一个独立的 Skill，可以单独下载、单独使用，各自记录版本。

## Skills

| Skill | 一句话介绍 | 当前版本 |
|---|---|---|
| [kaoyan-beiti 考研背题](kaoyan-beiti/) | 把论述题参考答案原文整理成理解版、答题版两份背诵稿和知识卡片 | v1.1.0 |

## 怎么用

1. 打开想要的 Skill 文件夹，看它的 README。
2. 下载整个仓库（**Code → Download ZIP**），把对应的文件夹放进 Claude 或 Codex 的 Skills 目录。

## 版本标签

每个 Skill 单独打标签，格式是 `skill名-v版本号`，比如 `kaoyan-beiti-v1.1.0`。更新记录在各自文件夹的 `CHANGELOG.md` 里。

# Changelog

## v1.1.0（2026-10-30）

- 每期完全独立：不再提“上一题”“上一期”；同一题拆成上下两期时，下期开头重报题目并回顾。
- 新增“语气”一节：从用户两轮亲手修改中总结出 11 条（聊天口吻、主持人带路、讲完停下来收一收、术语单独成行的固定句式、替听众说出“懵”、明确回到故事线等）。
- 新增“风格样例”：收入用户两轮“AI 原稿 → 手动修改稿”对比，要求动笔前先读、先揣摩。
- 首句改为“三明治”讲法：原句 → 大白话翻译 → 再念一遍原句 → 确认是否听懂；考试小标题逐行列出并对上故事画面。
- 主线强调连续画面（如“一天”：清晨、上午、中午、下午、深夜）；开场在报题后不再套用固定话术。
- 长度改为不针对任何语音工具：全文总字符数尽量不超过 10000，超了先压缩考试细节。
- 示例换成《西方美学史》第 7 题的完整逐字稿。

## v1.0.0（2026-10-29）

- 初版：把一道论述题做成单人讲故事式播客逐字稿（纯文本 TXT，供语音合成）。一道题一条故事主线，大白话先于术语，比喻不另加知识点。

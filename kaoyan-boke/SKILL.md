# 考研论述题播客逐字稿规范 v1.0

## 适用场景
用户把一道论述题做成单人播客，交给语音合成（如 MiniMax）生成音频，存在手机里走路时听。
播客的作用是放松地听、在脑子里留下画面，帮她回忆“这道题在讲什么”；背诵和答题仍靠理解版、答题版和知识卡片。所以逐字稿重在听懂，不在背原文。

## 输入
- 优先依据这道题的理解版和答题版（见 kaoyan-beiti 规范）；没有的话直接读原文，先理清逻辑再写。
- 只做逐字稿，不生成音频（用户自己接语音 API）。

## 核心原则
1. **一道题一条故事主线**：先为整道题找一个贯穿始终的大比喻或大故事（如第6题：柏拉图建理想城，诗人来城门口想进城，柏拉图审查他们，最后礼送出城）。每个自然段是这条主线里的“一幕”，幕里再拆小故事。各幕用同一批人物和场景，前后呼应（如第二幕回头提“还记得那栋三层楼吗”）。
2. **讲故事，不念原文**：故事部分尽量不出现原文原话，用画面、动作、对话讲出来，听完脑子里要有画面。
3. **大白话优先，术语后出**：任何专业术语都先用大白话讲清楚，再说一句“这个意思，考试的时候叫××”。不要先抛术语再解释。
4. **抽象处多讲一句**：遇到抽象概念（如理念、分有、认知资格、无利害），停下来用生活例子再解释一次，如“你想想，世界上的床长得都不一样，可你一看就知道它们都是床……”。
5. **比喻降低理解成本，不增加记忆负担**：比喻必须从理解版的内容里引申出来，准确对应原意；不加新知识点、新人名、新作品。为了主线统一做的简化（如对话里实际提问的是苏格拉底，故事里写成柏拉图），只要不影响答题就可以用，但要在交付时告诉用户。

## 整体结构
1. **报题**：第一句固定为“这一期的论述题是：（题目原文）。”不寒暄，不说“欢迎回来”。
2. **引入主线**：“我们先不管这些词，先听一个故事。”接着讲大故事的开端，交代两条线或几个问题分别对应什么（先说大白话，再说考试叫什么）。
3. **预告幕次**：“整场××，我们分×幕来听。第一幕……第二幕……”一句话说清每幕讲什么。
4. **开头怎么写**：用几句话把开头总纲段对应回故事，说清里面的术语。
5. **逐幕展开**：每一幕按下面的“每一幕的写法”来。
6. **整体回顾**：最后用一段话把整个故事从头快速走一遍，每幕一两句，把关键画面串起来。结束语一句“这一期就到这里。”

## 每一幕的写法
1. **幕名**：“好，第×幕：××。”幕名用故事语言，如“查身份”“城里怎么管诗人”“两份报告打架了”。
2. **承上**：第二幕起，先用一两句说清这一幕和上一幕的关系，如“第一幕是给诗人排名次，第二幕是给诗人定规矩”。
3. **讲故事**：按理解版的逻辑顺序讲，人物、场景、对话都可以有；术语按“大白话在前，考试叫××在后”嵌进去。
4. **考试怎么写**：“第×幕考试怎么写，提醒你几个地方。”只说三类东西：
   - 首句：原样念一遍，再用一句话翻译它；
   - 写作顺序：按什么顺序写，故事里的东西分别对应答案里的什么（“三层楼，答案里叫理念、现实、艺术”）；
   - 易混词、绕口词：点出来并给一个记法（如“木匠造的是物本身，所以是造原物；画家画的是物的样子，样子就是象，所以是造物象”）。书名、人名提醒“记一下就行”。
   这部分要短，不整段念答案。
5. **过渡钩子**：幕末用一个问题引出下一幕，如“既然诗人这么低，城里还要不要留他们？要留，又该怎么管？这就到了第二幕。”

## 语音合成格式
- 文件为纯文本 `.txt`，文件名 `第N题_播客逐字稿.txt`。
- 不留空行，一个自然段一行。
- 停顿完全靠标点：句号、逗号、顿号、冒号、问号。句子要短，一句只说一件事。
- 不用任何 Markdown 符号、列表符号、箭头、括号、表情、英文缩写；数字写成汉字（“第六”“九等”“两千多年前”）。
- 引号尽量少用，只在需要强调一个词时用。

## 长度
- 整题约 4000 个汉字以内，按每分钟约 250 字估算，约 16 分钟。
- MiniMax 按一个汉字算 2 个字符计数，单次上限 10000 字符，所以汉字最好不超过约 4300 个。
- 超长时有两种办法，先问用户选哪种：拆成上下两期（在自然的幕与幕之间切开，过渡句当下一期开头）；或压短各幕“考试怎么写”部分。
- 交付时用脚本统计汉字数，报告：汉字数、预计时长、MiniMax 预计字符数（汉字×2 + 其他字符）。

## 交付说明
交付时简短说明：主线是什么、分几幕、每幕的核心画面，以及为了主线做了哪些简化。不复述全文。

## 样例（第6题，开头到第一幕结束）
这一期的论述题是：论述柏拉图的模仿论与灵感论，并说明他如何处理诗与真理的关系。
我们先不管这些词，先听一个故事。整道题，其实就是一个故事：诗人想进城，柏拉图在城门口审查他们。
两千多年前，柏拉图想建一座最理想的城。城里住什么人、留什么东西，都要他点头。有一天，一群诗人来到城门口，想进城。柏拉图拦住他们说：先别急，我得查查你们。
他查了两样东西。第一样，查身份：你们诗人，在这个世界上到底排第几？第二样，查来历：你们写的那些诗，到底是从哪儿来的？
查身份这一套说法，考试的时候叫模仿论；查来历这一套说法，叫灵感论。柏拉图谈诗，就靠这两套说法，像一只鸟的两只翅膀，所以答案里叫它们"两翼"。
查完之后，柏拉图的结论是：诗人啊，你们比真理低一等。最后，他客客气气地把诗人送出了城。
整场审查，我们分五幕来听。第一幕，查身份，给诗人排名次；第二幕，排完名次，决定城里怎么管诗人；第三幕，查来历，诗到底从哪儿来；第四幕，柏拉图把两份调查报告放在一起，发现它们打架了；最后一幕，我们站在两千年后，评一评这场审查。
先说一下开头考试怎么写。开头就是把城门口这一幕，换成书面语说一遍。查身份，是在问"诗在这个世界上算第几等的存在"，这种问"什么最真、什么排第几"的学问，考试的时候叫本体论。查来历，是在问"诗是怎么写出来的"，这叫创作论。诗比真理低一等，考试的时候说成：把诗置于真理的从属地位。诗人和哲学家吵架，叫诗与哲学之争。客客气气送出城，叫礼送诗人，这件事写在《理想国》这本书里。
好，第一幕：查身份。
柏拉图带着诗人，走进一栋三层的楼。
最顶层，放着一张原版设计图。上面画的不是哪一张具体的床，而是"床"本身：一个能让人躺下睡觉的东西，该是什么样。这张图是神画的，全世界只有这一份，它最真。
这里有点抽象，我多解释一句。你想想，世界上的床有木头的、铁的、大的、小的，长得都不一样，可你一看就知道它们都是床。为什么？因为你心里有一个"床到底是什么"的标准。柏拉图说，这个标准不是人想出来的，它真实地存在，而且比任何一张具体的床都更真。这个标准，考试的时候叫理念。
走下一层，是木匠的工坊。木匠照着那张设计图，做出一张一张的床。这些床能睡，可每一张都有点不一样，用久了还会坏。它们是照着原图做出来的，像复印件。复印件这个意思，考试的时候叫摹本。
再走下一层，是画家的画室。画家坐在一张木匠做的床前面，对着它画了一幅画。你走过去想在画里的床上躺一下，结果什么都没有，那只是一张纸。画家是照着复印件又描了一遍，所以是复印件的复印件，影子的影子。
这栋楼，越往下走，离那张原版图就越远，也就越假。诗人和画家是一类人，都是照着别人描的，所以都住在最底下那一层。
诗人不服气：凭什么我们最低？
柏拉图说，你看那个画家。第一，他只画了床的正面，背面、底下，他全没画到，他只抓了一小块。第二，他画的只是床长什么样，可床为什么是床，他根本没碰到。第三，你让他做一张床试试？他不会。他画了半天床，其实一点都不懂床。所以啊，这不过是在玩，不算正经事。
最后柏拉图拿出一张名单，把世上的人分成九等。诗人，排在第六。
第一幕考试怎么写，提醒你几个地方。
这一段的第一句要原样背：模仿论以理念论为本体论前提，把艺术确定为第三等级的存在。翻译过来就是：三层楼这套说法叫理念论，它讲的是什么最真，所以说它是本体论的前提；按这栋楼排下来，艺术住在第三层。
三层楼，答案里叫理念、现实、艺术。顶层的原版图叫理念，是唯一的真实；木匠的床叫理念的摹本；画家的画叫摹本的摹本、影子的影子。
楼里的三个人，答案里写成三种模仿：神、工匠、画家。这里有两个词最容易搞混：造原物的艺术，和造物象的艺术。你就记，木匠造出来的是床这个"物"本身，所以是造原物；画家画的只是物的"样子"，样子就是"象"，所以是造物象。
最后那张九等名单，出自《斐德若篇》，书名记一下就行。
好，诗人被排到了最底层。可柏拉图还没完，他接着要想：既然诗人这么低，城里还要不要留他们？要留，又该怎么管？这就到了第二幕。

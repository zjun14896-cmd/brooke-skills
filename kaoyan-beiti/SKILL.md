# 考研论述题背诵规范 v1.1

## 适用场景
用户发来机构给的论述题参考答案（原文，常为 PDF），要整理成好背的材料。
目标是拿基础分上岸，不求面面俱到：宁减勿加，但得分点不丢。

## 产出与顺序
1. **理解版**（MD）：重排逻辑、补白话，用来读懂和做卡片。
2. **答题版**（MD）：从理解版压缩，用来背诵和考场作答。
3. **知识卡片**（PNG，一段一张）：依据理解版制作，用户要时再做。

## 通用铁律
- 每段首句（“第一，……”）原文照录、加粗，硬背。
- 专有名词、人名、作品名、引号里的原话、数字，一字不改。
- 不加新知识点、新人名、新作品、新观点；补的只能是对原文的解释、归位和连接。
- 字数只算汉字，标题行不算；完成后用脚本统计，向用户报告与原文的倍数。

## 一道题的结构
- **开头·总纲**：不分节，按“是什么 → 各管什么 → 合起来得出什么”排列。
- **主体段**（第一、第二……）：每段拆成 2 到 4 节，节与节有因果或递进关系。常见逻辑链：前提 → 过程 → 原因 → 结论；分类 → 理由 → 措施 → 限度；低 → 高 → 调和。按内容选，不硬套。
- **结尾·意义与局限**：首句加粗；分【意义】【局限】两节，各自分点。

## 改写操作
1. **拆节**：一整段按逻辑拆成几节，每节只做一件事。
2. **小标题**：每节一个，规则见两版各自说明。
3. **分点加短标签**：并列内容一行一点；每点前可加 2 到 4 字标签（如“取得少 / 离本质远 / 不懂行”）。主角是人物时直接用人物开头（神 / 工匠 / 画家）。
4. **例子归位**：原文里散落的例子、补充句，挪到它所属的那一点里（如床的例子拆进神、工匠、画家三条）。
5. **连接与指代**：用“所以、又、正因为、由此”连起来；“前者、后者”在不清楚时展开成具体名词；“前者导致……后者使……”这类统一交代的后果，挪回对应那一点的末尾。
6. **删重复**：同一意思说两遍的只留一次；“与之相应”“后二者分别被称为”这类绕弯连接合并掉。
7. **白话解释**（仅理解版）：难懂术语后跟一句“就是……”；整段的白话单独一行写成（白话：……）。
8. **小结与回扣**（仅理解版）：节末可加一句小结，段末可加一句回扣首句。

## 理解版规则
- 字数可到原文 1.5 到 1.9 倍。
- 小标题格式：**【一、功能词：一句话或问句】**，问句承接上一节，如【二、过程：艺术怎么落到第三层？以床为例，三种模仿一层层往下传】。
- 可用改写操作 1 到 8 全部。

## 答题版规则
- 字数不超过原文 1.2 倍，宁减勿加；但术语、作品、引语、数字、例子这些得分点不删。
- 小标题格式：**【一、4 到 6 字短标题】**，考场上照写，如【一、世界三分】【三、画家最低】。
- 可保留 2 到 4 字短标签。
- 不写白话、小结、回扣、结构预告、提示行。
- 分行只为好背，考场上连成段落写。

## 排版规则（两版通用，适配 Obsidian，导出 PDF 不浪费纸）
- 文件结构：`# 第N题　题目（理解版/答题版）`，然后 `## 开头·总纲`、`## 第一段`……`## 结尾·意义与局限`。
- 一点一行。并列项用 `- `；有顺序或数量的用 `1. `；对比项上下两行（前者 / 后者，低 / 高，当废 / 可存）。
- 节标题单独一行：`**【一、……】**`。
- 不用 `---` 分隔线，不用 `>` 引用框，不加提示行或用途说明。
- 空行：除同一组连续列表项之间不空行外，其余每行之间都空一行（标题、段首句、【小标题】、正文各自成段）。这样在 Obsidian 之外的任何 Markdown 预览里，小标题也不会被并到上一句后面。
- 文件名：`第N题_理解版.md`、`第N题_答题版.md`。

## 知识卡片规则
- 一段一张 PNG，结构与理解版一一对应：卡片上的①②③④就是【一二三四】。
- 顶部：段落标题（用问句，如“艺术为什么是第三等级？”）+ 首句框，核心词标红，旁注“原文硬背”。
- 主体：用空间走向表达逻辑。等级用阶梯下坡，对立用左右两边，传递用链条。同级节点格式统一：大标题 + 小字补充（如“理念世界 / 第一等 / 第一性的唯一真实”）。
- 每个人物或环节一个框：第一行原文，下面灰字“拿××来说：”白话解释，专有名称用浅蓝底标签。
- 原文没有、为串逻辑加的问句，用小字注明“原文没有这句问话”。
- 颜色：红色 = 必背原文术语；绿色 = 小标题、逻辑线、问句；浅蓝底 = 专有名称；灰色 = 白话解释（不用背）。
- 底部：绿色回答框（本段回答了什么）+ 数字自检（如“三个世界 · 三种模仿 · 九等第六”）+ 黄色“串引线”（一两行把整段连起来）。
- 风格：手绘感（SVG + feTurbulence 抖动滤镜）、米白底、圆角棕色外框、字体 Noto Sans CJK SC。用 HTML + SVG 画，Playwright 截图成宽 1500px 的 PNG。
- 截图后自己看一遍：文字有没有溢出或重叠，箭头有没有缺失（纯竖直或纯水平的直线加滤镜会消失，要用略带弧度的路径）。

## 工作流程
1. 读原文（PDF 用 Read 看页面），先逐字转录。
2. 出理解版 → 从理解版压缩出答题版 → 统计两版字数倍数。
3. 交付两份 MD，简短说明调了哪些顺序、删了哪些重复、补了哪些对比。
4. 用户要卡片时，按段制作。
5. 用户提的修改如果是通用规则，提醒可更新本规范，版本号加一。

## 样例（第6题第一段）

### 原文

第一，模仿论以理念论为本体论前提，把艺术确定为第三等级的存在。柏拉图将世界分为理念世界、现实世界与艺术世界：理念是第一性的唯一真实，现实是理念的摹本，艺术模仿现实，故为“摹本的摹本”“影子的影子”。《理想国》第十卷以床为例，床的理念是真实体，木匠不能制造“床之所以为床”而只能制造个别的床，画家所画又与真实体相去更远。与之相应有三种模仿：神模仿自身而产生理念，工匠模仿理念而制作事物，画家模仿事物而创作作品；后二者分别被称为“造原物的艺术”与“造物象的艺术”。画家只取事物的一小部分，而那一小部分还只是一种影像，他不模仿本质，“和真实体隔得很远”；模仿者对其题材没有有价值的知识，模仿“只是一种玩艺，并不是什么正经事”。故艺术美低于现实美，艺术作品低于工匠制品，因为后者直接模仿理念；《斐德若篇》分人为九等，诗人列第六等。

### 理解版

**第一，模仿论以理念论为本体论前提，把艺术确定为第三等级的存在。**

**【一、前提：世界分三层，越往下越不真实】**

柏拉图将世界分为理念世界、现实世界与艺术世界：

1. 理念世界最真：理念就是事物的本质，是第一性的唯一真实；
2. 现实世界次之：现实事物是照着理念造出来的，所以只是理念的“摹本”；
3. 艺术世界最假：艺术又是模仿现实事物，是模仿的模仿，所以是“摹本的摹本”“影子的影子”。

**【二、过程：艺术怎么落到第三层？以床为例，三种模仿一层层往下传】**

《理想国》第十卷以床为例，与这三个世界相应有三种模仿：

1. 神模仿自身而产生理念。拿床来说，床的理念就是“床之所以为床”，也就是床的本质，叫“真实体”，这是神创造的，不是人做的；
2. 工匠模仿理念而制作事物。木匠照着床的理念，造出一张张具体的床，但他不能制造“床之所以为床”本身，只能制造个别的床，这是“造原物的艺术”；
3. 画家模仿事物而创作作品。画家又照着这张具体的床，画出一张床的影像，比木匠又隔了一层，所画与真实体相去更远，这是“造物象的艺术”。

这三层就是：神、工匠、画家，对应理念、事物、影像，一层比一层更远。

**【三、原因：画家处在最末一层，为什么最低？】**

正因为画家离真实体最远，他有三个问题：

1. 取得少：他只取事物的一小部分，而那一小部分还只是一种影像；
2. 离本质远：他不模仿本质，“和真实体隔得很远”；
3. 不懂行：模仿者对其题材没有有价值的知识，所以模仿“只是一种玩艺，并不是什么正经事”。

**【四、结论：所以艺术只能排第三，诗人排第六】**

由此，艺术美低于现实美，艺术作品低于工匠制品，因为工匠制品直接模仿理念，而艺术作品模仿的只是事物。

《斐德若篇》把人分为九等，诗人列第六等。

所以在本体论上，艺术只是第三等级的存在。

### 答题版

**第一，模仿论以理念论为本体论前提，把艺术确定为第三等级的存在。**

**【一、世界三分】**

柏拉图将世界分为理念世界、现实世界与艺术世界：

- 理念：第一性的唯一真实；
- 现实：理念的摹本；
- 艺术：模仿现实，故为“摹本的摹本”“影子的影子”。

**【二、三种模仿】**

《理想国》第十卷以床为例，相应有三种模仿：

- 神模仿自身而产生理念，即“床之所以为床”的真实体；
- 工匠模仿理念而制作事物，只能造个别的床，是“造原物的艺术”；
- 画家模仿事物而创作作品，只画出床的影像，与真实体相去更远，是“造物象的艺术”。

**【三、画家最低】**

- 取得少：画家只取事物的一小部分，而那一小部分还只是一种影像；
- 离本质远：他不模仿本质，“和真实体隔得很远”；
- 不懂行：对其题材没有有价值的知识，模仿“只是一种玩艺，并不是什么正经事”。

**【四、等级结论】**

- 故艺术美低于现实美，艺术作品低于工匠制品，因为后者直接模仿理念；
- 《斐德若篇》分人为九等，诗人列第六等。

# Chrome、AIPrice 与长截图

## 连接与入口

这套流程已在用户 Chrome 的扩展连接方式上验证。原生桌面控制有时无法读取 Chrome 标签页地址；这不等于用户没有全屏，也不应把“全屏”作为前提。使用当前环境提供的 Chrome 浏览器连接，按当前文档初始化和获取标签页。会话 ID、标签 ID、坐标、临时目录每次重新获取，不沿用历史值。

AIPrice 在受支持的网页中注入界面。当前已验证的宿主是出海匠已登录商品页面。可复用宿主页面，直接在 AIPrice 上传原图，不需要另跑出海匠六款商品采集。不要为激活插件去尝试已被安全策略阻止的1688详情页，也不把未经验证的独立扩展地址当入口。

AIPrice 左侧可能同时保留多张上传图。核对当前选中图、搜索平台和国家。左侧平台列表滚动至 `Google Lens`；菜单滚动完成后，应在右侧商品网格滚动加载更多结果。点击 `Amazon` 时核对不是 `Amazon Lite`，站点 US。保留用户当前配送地址设置；Amazon.com 站点与页面的配送国家不是同一概念，不必为截图改地址。

## 已验证的页面取数方式

用最新 AX、DOM 或截图定位控件。插件内容可能在注入面板或 shadow root 中，普通文本定位器找不到时不能据此判定没有信息；先查看截图及当前 DOM，再使用工具允许的只读 DOM 访问或截图定位。

曾用到的相似页候选卡片选择器为 `#product_grid_container .cellContainer`。仅在本次 DOM 确认存在、布局一致时使用，不把它当永久接口。批量读取卡片可保留原序、商品/卖家链接和插件文本；读取 DOM 不替代真实截图。

插件可能晚于 Amazon 主体出现。等待 ASIN、卖家和上架时间字段显示再读取。`找货-Amazon` 通常打开新标签；从当前标签清单识别新页面，不复用上次搜索的相似结果。

## 捕捉办法

1. 在结果区域逐段向下滚动，使目标16/12项的图片及插件内容都加载；观察最后一项，确认没有加载占位或空白卡片。
2. 恢复结果顶部，把鼠标移到标题或空白处，消除商品悬停工具条和遮挡。不移动浏览器窗口、不改变用户系统缩放作为默认操作。
3. 优先使用当前工具支持的整页截图，**先不指定 clip**，保存到临时目录。查看实际图片尺寸和内容，再按图中真实像素裁出目标区域。
4. 现场曾出现 `fullPage:true` 与 `clip` 一起使用后，第一列被截掉、底部多出半排的现象。DOM 的坐标与整页截图像素范围可能不完全对应；不要直接把历史 DOM 矩形当作最终裁切框。整页原图后裁切更稳。
5. 整页截图只捕到外层页面、无法展开内部滚动容器时，改为在网格内滚动截取带重叠的多张真实截图，再按重叠卡片对齐拼接。裁掉重复固定表头、悬浮广告和重复卡片；不能拉伸卡片、补造下半部。
6. 拼接/裁切用本地确定性图像工具。输出 PNG，目视检查首项、末项、每列边缘与拼接位置，确认数量正确、文字可读、无漏行或重复行。中间图留在临时目录。

## 商品详情截图

为六条入选记录分别截真实商品详情页；主图、当前款式、美元价格、插件 ASIN/卖家/日期应可核对。截图尺寸可以随当前窗口变化，嵌表时按实际宽高等比缩放，不硬编码上次窗口比例。下拉过深时先回到商品主要区域，避免只截推荐商品或评论区。

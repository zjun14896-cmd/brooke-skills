# aiprice-amazon-sourcing

AIPrice 图搜与 Amazon 六家公司采集 1.0：用一张产品图，经 Chrome AIPrice 插件完成 Google Lens 图搜和 Amazon 相似商品搜索，按原序采集六家不同公司（按 Business Name 去重）的资料。出海匠只作为插件宿主。

## 交付内容

- `Amazon六家公司采集.xlsx`：六家不同公司，含卖家、ASIN、价格、上架时间、Business Name / Address，以及每款详情页截图
- `Amazon相似商品首页_长截图_前12项.png`
- `Google Lens 截图_长图_前16项.png`
